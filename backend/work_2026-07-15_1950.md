# CSI 集成收尾 + IndexValuation 修复 (2026-07-15 19:50)

## 问题
用户截图：估值页面有指数无数据（930901/H30533/931484/HSTECH 全部显示"暂无分位数据"）

## 根因
`IndexValuation.vue` 模板的 v-if 判断：
```vue
v-if="idx.data_source === 'manual'"  ← 只识别手动来源
```
CSI 自动计算的分位（`data_source === 'csi_10y'`）被误判为"暂无分位数据"。

## 修复内容

### 1. `valuation_service.py` - 补全 CSI_INDICES 映射
```python
CSI_INDICES = {
    "930901": "中证动漫游戏指数",
    "H30533":  "中证海外中国互联网50",
    "931484":  "中证医药创新",
    "931152":  "中证创新药",
    "931087":  "中证科技龙头",
    "399986":  "中证金融",
}
```

### 2. `csi_service.py` - 加进程内缓存
- 实时 PE：1 小时 TTL
- 历史 PE：24 小时 TTL
- 解决 6 个指数同步拉历史 11 秒慢响应（缓存后 < 100ms）

### 3. `IndexValuation.vue` - 修复判断逻辑
- `v-if` 改为 `hasPct(idx)`（识别 manual/csi_10y/local_snapshot）
- 新增数据来源徽章：
  - M（蓝）= 手动
  - C（紫）= 中证 10年历史
  - S（绿）= 本地快照
- 卡片底部按钮区分：
  - 手动 → "📝 修改分位"
  - CSI/本地 → "✏️ 覆盖为手动"
  - 无分位 → "📊 填分位"
