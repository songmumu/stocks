# 2026-07-16 10:53 - 指数删除按钮全量支持

## 用户反馈
截图显示 CSI 行业指数（931484/931152/931087/399986）只显示"覆盖为手动"按钮，没有删除按钮。
只有 000680/000015（is_custom=True）有删除按钮。

## 根因
- 之前 `IndexValuation.vue` 的删除按钮有 `v-if="idx.is_custom"` 条件
- CSI 指数硬编码在 `valuation_service.py` 的 `CSI_INDICES` 字典里
- 腾讯宽基指数硬编码在 `WATCHED_INDICES` 字典里
- 这两类非自定义指数没有删除入口

## 修复方案
新增 `HiddenIndex` 表（替代物理删除），让任何指数都可隐藏：
- 自定义指数：物理删除 `CustomIndex` 表
- 内置/CSI指数：加入 `HiddenIndex` 表（不破坏硬编码）
- `/api/valuation/indices` 列表过滤 `hidden_indices`
- 删除按钮 `v-if` 条件移除，所有指数都显示

## 文件变更
- `backend/app/models.py` +11 行：新增 `HiddenIndex` 模型
- `backend/app/routers/valuation.py` +2 行：导入 `HiddenIndex`，过滤 `hidden_codes`
- `backend/app/routers/custom_indices.py` 重写 DELETE 处理器：
  - 物理删除自定义指数
  - 内置/CSI 指数加入 `HiddenIndex` 表
- `frontend/src/views/IndexValuation.vue` 移除 `v-if="idx.is_custom"` 条件

## 验证
- API 测试：删除 931087（中证科技龙头）→ `action: hidden`
- 列表过滤：15 → 14 个指数
- 恢复 931087 后 14 → 15

## 隐藏指数恢复方式
如需恢复误删的指数，直接操作数据库：
```python
from app.database import SessionLocal
from app.models import HiddenIndex
db = SessionLocal()
db.query(HiddenIndex).filter(HiddenIndex.code == '931087').delete()
db.commit()
```
