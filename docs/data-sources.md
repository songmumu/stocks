## 3. 行情数据源

### 实时行情（股票/ETF）→ 腾讯
- 接口：`https://qt.gtimg.cn/q=<secid>`
- 字段：[0]名称 [1]代码 [3]现价 [6]涨跌额 [32]振幅 [38]换手率 [39]PE [43]PB
- 同时返回：name/现价/PE/PB
- GBK 编码，需 `codecs.decode(name, 'gbk')`

### 基金净值（场内/场外通用）→ 天天基金
- 接口：`https://fundmobapi.eastmoney.com/FundMNewApi/FundMNHisNetList`
- 必须带 Referer: `https://fundf10.eastmoney.com/`
- 场外基金（018816）：行情返回 `no_intraday`，净值取 K 线最后一条 `close`

### K 线历史 → 东方财富 push2his
- 接口：`https://push2his.eastmoney.com/api/qt/stock/kline/get`
- 支持 30/60/120/250 日切换

## 4. 数据流总览

```
┌─────────────────────────────────────────────┐
│  行情/价格 (实盘)                            │
│  ├─ 股票/ETF: 腾讯 qt.gtimg.cn              │
│  └─ 场外基金: 天天基金 FundMNewApi          │
├─────────────────────────────────────────────┤
│  K 线 (历史)                                │
│  └─ push2his.eastmoney.com (30-250 日)     │
├─────────────────────────────────────────────┤
│  估值 (分位)                                │
│  ├─ 7 个宽基: 腾讯 PE + 本地快照分位        │
│  ├─ 6 个行业: CSI 10 年历史分位             │
│  └─ ETF: 通过 ETF_TO_INDEX 关联             │
├─────────────────────────────────────────────┤
│  个股/场外基金: 无标准估值，仅看价格         │
└─────────────────────────────────────────────┘
```
